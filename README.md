# SciWrite Academy — Final

A static, tablet-friendly learning platform for the archived Writing in the Sciences course.

## Final features
- 8-unit course navigation with collapsible lesson lists
- 67 video entries including extra/demo videos
- YouTube watched-progress tracking saved locally
- lesson guides, knowledge checks, bookmarks and rich notes
- My Research Workspace for Abstract, Introduction, Methods, Results and Discussion
- Writing Review Lab using the labarba/sciwrite methodology
- AI prompt handoff without exposing an API key
- Review Center, search, dark mode, backup/restore and personal progress
- mobile/tablet sidebar with click-outside dismissal

GitHub Pages remains the intended deployment target. The site is static; a true embedded AI model would require a secure backend because GitHub Pages does not run server-side code.
